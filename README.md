# Glider CAD

SolidWorks design of a small glider, modelled after I built a physical coroplast glider at a hands-on drone and glider workshop. The goal was to understand the airframe properly: how the fuselage, main wing and tail come together, and how the design changes between iterations.

![Glider isometric view, version 1.1](Gallery/Version%201.1/Isometric.jpeg)

## What is inside

| Folder | Contents |
| :--- | :--- |
| [`Components/`](Components) | SolidWorks parts: fuselage, main wing, tail wing (`.SLDPRT`) |
| [`assembly/`](assembly) | Full assembly, with and without wings (`.SLDASM`) |
| [`3d models/`](3d%20models) | STL exports of each part, ready for viewing or 3D printing |
| [`Gallery/`](Gallery) | Renders, wireframes and the engineering drawing for each version |

## Versions
